# Gemini 3.8 Flash

**Gemini 3.8 Flash** is Google’s September 2026 workhorse model for fast coding, reasoning, search-heavy knowledge work, and agent workflows.

## Reported position

The sources describe a low-cost model with $0.75 per million input tokens and $3.75 per million output tokens. Coverage reports gains over Gemini 3.7 Flash and strong results across selected agentic, legal, finance, vision, biology, and reasoning evaluations, while premium models still lead some harder coding and long-horizon slices. [raw/newsletters/the-neuron-2026-09-03-new-google-meta-and-maybe-openai-models.md][raw/newsletters/ainews-2026-09-02-ainews-claude-fable-mythos-5-1-new-sota-model-75-cache-price-cut-but-7.md]

## Practical significance

Gemini 3.8 Flash belongs to the new “completed-task economics” comparison. It is reported as fast and cheap per token, but one comparison found it roughly 40% more expensive per completed task than Muse Spark 1.3 because it did more work. That is a workload-specific signal, not a universal ranking. [raw/newsletters/the-neuron-2026-09-03-new-google-meta-and-maybe-openai-models.md]
