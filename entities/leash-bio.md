# Leash Bio

**Leash Bio** is a biotechnology company using DNA-encoded libraries to generate high-throughput protein–small-molecule interaction data for modeling and drug discovery.

## Why it matters

The source presents Leash's contribution as an epistemic and data-quality problem before it is a model-scaling problem. Careful experimental design and controls make noisy library measurements reproducible enough to support large-scale learning, while prior competitions showed that performance on an unseen chemical library can remain near chance even with billions of measurements. [raw/newsletters/latent-space-2026-10-14-lab-in-the-loop-at-compute-speed-ian-quigley-leash-bio.md]

Leash's Minos project turns its experimental data into an agent sandbox for verifiable scientific reasoning. Agents can reason about structure–activity relationships and search millions of molecules against simulated lab feedback, creating a bridge between scientific agents, reinforcement learning, and experimentally grounded evaluation.
