# Runway Solaris

**Runway Solaris** is Runway’s reported “Interface World Model,” a system that generates interactive software interfaces frame by frame instead of writing the UI code first.

## What it does

Solaris is described as a real-time model built on Gen-4.5. It predicts the next screen after a click or drag, allowing an interface to be generated on demand. The Neuron reported that 250 evaluators preferred Solaris over Claude Opus 5-coded interfaces in 61% of instruction-following comparisons and 71% of natural-behavior comparisons; access was request-only at capture time. [raw/newsletters/the-neuron-2026-09-01-runway-solaris-treats-software-like-video.md][raw/newsletters/ainews-2026-09-01-ainews-fal-s-h3-max-live-breaks-the-infinite-videogen-barrier.md]

## Why it matters

Solaris treats the rendered frame as both interface and simulation. That could reduce the need to prebuild every screen state, but it moves reliability requirements into visual continuity, state persistence, accessibility, security, recoverability, and consistent interaction semantics. The next meaningful test is boring repeated work, not a single impressive screen. [[agent-experience]] and [[ai-benchmarking]] provide the right lens.
