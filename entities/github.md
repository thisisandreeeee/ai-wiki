# GitHub

**GitHub** appears as the collaboration layer that has to absorb agent-generated software work without losing trust, reviewability, and maintainer control.

## Corpus signals

- Latent.Space’s GitHub interview described an AI-driven scale problem: agent activity can expand commits, pull requests, actions, and review load at machine speed.
- Copilot is evolving from code completion into CLI, desktop app, cloud agents, SDKs, canvases, and cross-device workflows.
- GitHub’s core challenge is social and operational: preserving review trust and open-source norms while agents produce more proposed changes.

## Why it matters

GitHub connects [[coding-agent-evaluation]] to real workflow outcomes. Passing tests matters less if maintainers cannot audit provenance, scope, risk, and intent.
