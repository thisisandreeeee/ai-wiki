# Lovable

**Lovable** is an AI application-building and hosting platform that the late-August Latent.Space interview describes as evolving toward an agent-accessible “company brain.” Its users can build conventional interfaces while exposing selected application functions as capabilities through a hosted MCP server.

## From apps to capabilities

The key product idea is that one application can have both a human UI and an agent interface. An organization-wide agent can call reliable capabilities directly, schedule itself to resume work, and connect workflows that previously required many separate SaaS tabs. The platform’s stated challenge is not orchestration alone; it is building connected capabilities with correct permissions and dependable behavior. [raw/newsletters/latent-space-2026-08-26-the-future-of-saas-is-apps-that-agents-can-use.md]

Lovable’s connector design keeps external credentials server-side and binds access to the user’s identity and source-system permissions. That is a useful pattern for [[llm-application-interface]] and [[agent-reliability-and-operations]], but it does not remove the need for permission graphs, auditability, and human approval around consequential actions.
