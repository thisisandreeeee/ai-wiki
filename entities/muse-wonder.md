# Muse Wonder

**Muse Wonder** is Meta's October 2026 frontier model for coding, personal assistance, and multi-step agentic work. **Wonder Full** is the higher-capability variant available through Muse Code plans rather than the public API.

## Reported position

Meta's launch emphasizes **Active Memory** for maintaining relevant personal context and **Active Focus** for persistence, recovery, and trying alternative approaches when a task stalls. Independent reports place Wonder near the frontier but below Opus 5.5 on Artificial Analysis's Intelligence Index; comparisons vary by benchmark, harness, effort setting, and model variant. [raw/newsletters/the-neuron-2026-10-13-meta-s-muse-wonder-is-here-priced-like-opus.md][raw/newsletters/ainews-2026-10-13-ainews-meta-muse-wonder-wonder-full-msl-s-claude-5-5-tier-frontier-mod.md]

Wonder is available through Meta's Model API and Muse Code, while Wonder Full is restricted to Muse Code plans. Early reports also describe expensive quotas, rollout bugs, and a Pokémon run that spent hours wandering without reaching the first gym; these are workload-specific observations, not a general reliability benchmark. [raw/newsletters/ainews-2026-10-14-ainews-ai-engineer-nyc-gemini-4-argon-vals-ai-benchmarks.md]

## Safety and privacy questions

The Muse Code experience reportedly defaults to a contributor mode that allows Meta to use submitted material for model training unless disabled. The API is described separately as not training on customer content. Active memory therefore makes data retention, deletion, and training settings part of the model's product surface, not merely an implementation detail. [raw/newsletters/the-neuron-2026-10-13-meta-s-muse-wonder-is-here-priced-like-opus.md]

Meta's safety materials also leave open chemical and biological misuse risk without mitigations. Whether Active Focus improves reliable recovery on long, boring, consequential tasks remains an open question.
