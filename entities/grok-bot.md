# Grok Bot

**Grok Bot** is xAI’s managed agent-computer product, presented in the September 2026 batch as a simpler alternative to user-operated agent platforms such as [[openclaw]].

## Product model

Users connect services through a plugin catalog and browser sign-in rather than manually wiring MCP configuration or API credentials. A Bot can have a named role, connect to tools, run recurring workflows, and compose with other Bots in a group chat. The product’s abstraction shifts programming toward specifying intent and delegating to a role. [raw/newsletters/latent-space-2026-09-05-openclaw-power-macbook-simplicity-five-days-with-grok-bot.md]

The managed computer is the key distinction. xAI operates the persistent cloud machine, browser sessions, updates, and recovery, while [[openclaw]] leaves the user responsible for more of the Gateway and host. The convenience tradeoff is less control over model choice, context, effort, and capacity. Separate Bots also share the same computer, files, browser sessions, and logins, so they are organizational boundaries rather than automatic security boundaries. [raw/newsletters/latent-space-2026-09-05-openclaw-power-macbook-simplicity-five-days-with-grok-bot.md]

## Best fit

The source’s practical verdict is that Grok Bot is strongest as a digital chief of staff for administration, summaries, news, project management, and other work around deep engineering—not as a replacement for hands-on implementation. [[agent-experience]] and [[model-routing]] capture the design tradeoff.
