# Open Code Data

**Open code data** is publicly available, license-aware source-code training data used to build or evaluate code models.

## July 2026 signal

AINews described The Stack v3 as a major open-data release: 114 TB raw, 224M repositories, 44B files, 770 languages, and roughly 5T deduplicated/filtered tokens, with a fresh GitHub recrawl through August 2025 and licensing filters. [raw/newsletters/ainews-2026-07-24-ainews-black-forest-labs-flux-3-multimodal-flow-models-that-beat-seeda.md:34-36]

The significance is strategic as much as technical. A large, public, license-filtered code corpus raises the floor for open code models and cyber-defense tooling, reducing dependence on closed model ecosystems or opaque training mixtures.
