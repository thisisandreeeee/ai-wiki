### [How to Learn ML in 2026](https://vickiboykis.com/2026/10/17/how-to-learn-ml-in-2026-interview/?utm_campaign=Data_Elixir&utm_source=Data_Elixir_595)

As AI agents take on more coding and data work, which technical skills still matter? In this interview, Vicki Boykis makes the case for ML fundamentals, hands-on data exploration, and deep systems knowledge. She also shares practical examples of where delegating work to agents helps and where it gets in the way.
_Vicki Boykis_


--------------------
### [Nonlinear Formulas in Bambi: Gelman’s Golf Putting](https://tylerjamesburch.com/blog/statistics/nonlinear-formula-bambi-golf-putting?utm_campaign=Data_Elixir&utm_source=Data_Elixir_595)

Logistic regression gets the basic trend in golf putting right, but it misses the shape. This post shows how to use Bambi’s new nonlinear formula support to model the geometry of a putt and capture that shape. Includes code and examples ranging from enzyme kinetics to tree growth.
_Tyler James Burch_


--------------------
### [A Primer for Earth Data Embeddings](https://developmentseed.org/blog/2026-10-02-earth-embeddings/?utm_campaign=Data_Elixir&utm_source=Data_Elixir_595)

Geospatial foundation models turn satellite imagery and other Earth observation data into embeddings that support similarity search, clustering, and change detection. This is a great primer that explains how those representations work, where they're useful, and how to get started with existing embedding datasets or generate your own using open-source models.
_Development Seed | Kiri Carini & Martha Morrissey_


--------------------
### [Tips and Tricks for Faster Grouped Operations in base R](https://nathaneastwood.github.io/2026/10/25/poorman-tips-and-tricks-for-faster-grouped-operations-in-base-r/?utm_campaign=Data_Elixir&utm_source=Data_Elixir_595)

The expensive part of a grouped calculation isn't always the calculation itself. Sometimes it's splitting data frames, repeatedly evaluating R code, and combining the results. This post explores six ways to eliminate that overhead and get up to 20x speedups over base R alone.
_Nathan Eastwood_


--------------------
### [Is doomsday three weeks away?](https://kucharski.substack.com/p/is-doomsday-three-weeks-away?utm_campaign=Data_Elixir&utm_source=Data_Elixir_595)

In 1960, a mathematical model predicted that the world’s population would reach infinity in November 2026. The model fit the historical data beautifully, which is exactly the problem. From smallpox forecasts of 77 trillion cases to Olympic sprint crossovers, this is a fun tour of why good fits make terrible forecasts.
_Understanding the unseen |  Adam Kucharski_


--------------------
### [Training Better Agents](https://www.mercor.com/blog/mercor-nvidia-nemotron-3-5/?utm_source=dataelixir&utm_medium=newsletter&utm_term=apex&utm_content=10_27)

Mercor tested whether small, targeted datasets could make AI agents better at real work, and the results were promising. Across legal, coding, and accounting tasks, the models didn't just score better. They became more likely to consult documents, check their work, and use tools effectively.

### [Still Bivariate, Still Curious](https://www.joshuastevens.net/blog/still-bivariate-still-curious/?utm_campaign=Data_Elixir&utm_source=Data_Elixir_595)

It used to take a lot of manual work to create bivariate maps, but new tools have simplified the process. ### [Announcing DuckDB 2.0.0 LTS](https://duckdb.org/2026/10/21/announcing-duckdb-200?utm_campaign=Data_Elixir&utm_source=Data_Elixir_595)

DuckDB started as a lightweight, embedded analytical database, but with version 2.0, it's becoming something much broader. This major release adds client-server capabilities, faster queries on cloud storage, better support for semi-structured data, and a CLI designed to work with AI agents.

--------------------
### [commons - for building trustworthy data analysis agents](https://posit-dev.github.io/commons/?utm_campaign=Data_Elixir&utm_source=Data_Elixir_595)

If you already have analysis code you trust, there’s no reason for an AI agent to start from scratch. Posit’s commons package has agents try your vetted functions first and write new code only when nothing fits. Each answer is labeled by the path it took, not the model’s own confidence, so you know what to trust. Available for R now, with Python in beta.
_Posit_
