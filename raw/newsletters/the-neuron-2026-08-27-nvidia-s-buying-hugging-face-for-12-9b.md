# 😺 Nvidia is buying the place where the entire AI industry keeps its models

A few weeks ago, Hugging Face [was breached by OpenAI's own rogue agents](https://www.reuters.com/technology/nvidia-talks-acquire-hugging-face-13-billion-deal-business-insider-reports-2026-08-27/) that escaped their sandbox (a locked-down practice environment) and hacked their way in. Now the company whose chips train those very agents wants to buy the place outright.

**Here's what happened:**

* Nvidia has agreed to buy Hugging Face for $12.9 billion, according to The Information, in a deal first reported as "talks" by Business Insider just days earlier.

* Hugging Face is often called the "GitHub of AI" (a reference to the site where software developers store and share code): it's the default place developers go to find, share, and deploy AI models and datasets.

* Nvidia already backed Hugging Face at a $4.5 billion valuation back in 2023, alongside Google and Salesforce. Earlier this year, it offered $500 million for a stake that would've valued the company at $7 billion; Hugging Face turned it down.

* Neither company has confirmed the deal publicly yet.

**Our take:** Nvidia already controls the chips that train and run most AI models. Buying Hugging Face hands it the software and community layer too, deciding where those models actually live. If your team's ever pulled an open-source model at work, it probably came through Hugging Face, whether you knew the name or not. There's irony here too: OpenAI's own agents hacked this same platform last month while cheating on a benchmark.

It also fits a pattern. Nvidia has poured $40 billion-plus into AI equity deals in 2026 alone, including a $30 billion OpenAI stake, deals critics call "circular financing" (Nvidia backing companies that buy Nvidia chips with the money). Huang calls that label "simply ridiculous." Buying Hugging Face outright is different: Nvidia owning infrastructure, not just funding a customer.

The open question: does Hugging Face's neutral, open-source reputation, the thing that made it valuable, survive being owned by the company with the most to gain from picking winners?

# 🎓 AI Skill of the Day: Make Claude and Codex Share a Project Brain

Claude Code and Codex can share project instructions even though they look for different files. [Codex reads ](https://learn.chatgpt.com/docs/agent-configuration/agents-md)`AGENTS.md`; [Claude Code reads ](https://code.claude.com/docs/en/memory)`CLAUDE.md`, and Anthropic says that file can import an existing `AGENTS.md`.

1. Put shared project rules in `AGENTS.md`, including: read `STATUS.md` first and update it before stopping.

2. Keep `STATUS.md` to the current goal, completed work, decisions, tests, blockers, and next action.

3. Make `CLAUDE.md` simply import the shared file:

```
@AGENTS.md
```
Now either agent can open the same repo, read the handoff, and continue without a giant recap.

**Tiny **`STATUS.md`** template:**

```
# Goal
# Done
# Decisions
# Tests
# Blockers
# Next action
```
