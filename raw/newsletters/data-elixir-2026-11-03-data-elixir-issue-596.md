### [My Messy Notes of Learning MICE From Scratch](https://www.kenkoonwong.com/blog/mice/?utm_campaign=Data_Elixir&utm_source=Data_Elixir_596)

Filling missing values with a single best guess can make your statistical estimates look more certain than they really are. Multiple imputation offers a better approach by creating several plausible versions of the missing data to account for uncertainty. This hands-on walkthrough builds MICE from scratch in R and compares the results with an established implementation.
_Ken Koon Wong_

### [When Do Causal ML Models Beat LM / GLM / GBM?](https://philipppro.quarto.pub/blog_philipppro/posts/causalml-toy-cases/ ?utm_campaign=Data_Elixir&utm_source=Data_Elixir_596)

A model can predict which customers will cancel and still be terrible at identifying which customers a retention offer could save. That's one of many lessons in this hands-on comparison of causal ML methods and traditional models, using simulations where the true effects are known.
_Philipp Probst_

### [How to make interactive charts you can email](https://nrennie.rbind.io/blog/interactive-charts-ggiraph/?utm_campaign=Data_Elixir&utm_source=Data_Elixir_596)

This hands-on R tutorial combines ggplot2, ggiraph, htmltools, and Quarto to create self-contained interactive charts. It covers hover tooltips, dropdown filters, and a little bit of JavaScript to connect everything. The final result is an HTML file that anyone can open locally without a server.

### [Dogs of New York, Shapes and Sizes Edition](https://kieranhealy.org/blog/archives/2026/10/25/dogs-of-new-york-shapes-and-sizes-edition/?utm_campaign=Data_Elixir&utm_source=Data_Elixir_596)

Do bigger dogs live where there’s more room? Mostly not.
