# Tools & Code


--------------------
### [BigSet](https://github.com/tinyfish-io/bigset?utm_campaign=Data_Elixir&utm_source=Data_Elixir_577#readme)

BigSet turns plain-English dataset ideas into structured tables. Describe what you want, and it infers a schema, researches public web sources, verifies and deduplicates rows, then exports CSV or XLSX. It’s experimental, but the idea here is compelling: lightweight, refreshable datasets without hand-building a scraper first. 
_GitHub | TinyFish_


--------------------
### [SQL to ER Diagram](https://github.com/royalbhati/sqltoerdiagram/tree/main?utm_campaign=Data_Elixir&utm_source=Data_Elixir_577#readme)

SQL schemas are easier to understand when you can see the relationships. This open-source browser tool turns CREATE TABLE statements into an interactive ER diagram, with local-only processing, relationship highlighting, and inline edits that update the SQL. The repo describes it, and [here’s a live example.](https://sqltoerdiagram.com/?utm_campaign=Data_Elixir&utm_source=Data_Elixir_577)
_SQL to ER Diagram | Royal Bhati_

###  [A Fossil Mystery](https://github.com/Hawzen/I-found-a-seashell-in-the-middle-of-the-desert?utm_campaign=Data_Elixir&utm_source=Data_Elixir_577#readme)

Mohand Alrasheed found a seashell in the middle of the desert and wanted to know why. From there, he turns shell identification into a shape-analysis problem, using contour extraction, shape normalization, PCA, and latent-space mapping to compare shell forms.
